1. THE BIG PICTURE: HOW FULL-STACK DEPLOYMENT WORKS
--------------------------------------------------------------------------------
Every modern full-stack web application is split into 3 independent parts:

  [ FRONTEND (Vercel) ]
         │  (HTTP / API Requests)
         ▼
  [ BACKEND (Render) ]
         │  (Database Connection)
         ▼
  [ DATABASE (MongoDB Atlas) ]

  • DATABASE (MongoDB Atlas):
    - Stores all books, users, orders, categories, and reviews.
    - Runs in the cloud 24/7.
    - Has a firewall (Network Access) that only allows trusted IP addresses.

  • BACKEND (Render):
    - Runs your Node.js & Express server.
    - Receives requests from the frontend, queries MongoDB, and returns JSON.
    - Connects to MongoDB via MONGO_URI.
    - Listens on port 10000 and 0.0.0.0.

  • FRONTEND (Vercel):
    - Hosts your React + Vite HTML/CSS/JS files globally on a CDN.
    - Connects to your backend via the environment variable VITE_API_URL.
    - Very fast, loads in milliseconds worldwide.

4. DEPLOYMENT QUICK CHECKLIST (Save for reference)
================================================================================
Step 1: MongoDB Atlas
  [ ] Cluster created
  [ ] Database user created (username & password)
  [ ] Network Access -> Add IP Address -> 0.0.0.0/0 (Active)
  [ ] Copied connection string (MONGO_URI)

Step 2: Render (Backend)
  [ ] New Web Service -> Connected GitHub repo
  [ ] Root Directory set to: server
  [ ] Build Command: npm install
  [ ] Start Command: node index.js
  [ ] Environment Variables added:
      - NODE_ENV = production
      - MONGO_URI = (your connection string)
      - JWT_SECRET = (your secret)
      - RAZORPAY_KEY_ID = (your key)
      - RAZORPAY_KEY_SECRET = (your secret)
      - FRONTEND_URL = (your Vercel URL)
  [ ] Status is green "Live"

Step 3: Vercel (Frontend)
  [ ] New Project -> Connected GitHub repo
  [ ] Framework Preset: Vite
  [ ] Environment Variables:
      - VITE_API_URL = (your Render live URL, e.g. https://your-api.onrender.com)
  [ ] Deploy clicked -> Website is live!
